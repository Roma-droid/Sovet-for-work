# Sovet-for-work

Телеграм-бот для подростков и взрослых, которые хотят найти новые, интересные и осознанные пути развития своей карьеры.

## Что делает проект

- Помогает пользователям сформулировать карьерные цели
- Предлагает идеи для развития навыков и профессионального роста
- Служит источником мотивации при поиске новой работы или смене направления

## Кому это полезно

- подросткам, ищущим первые шаги в профессии
- людям, которые устали от текущей работы
- тем, кто хочет понять, в каком направлении развиваться дальше

## Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Roma-droid/Sovet-for-work.git
   cd Sovet-for-work
   ```
2. Установите зависимости (если появятся):
   ```bash
   pip install -r requirements.txt
   ```

## Запуск

1. Создайте Telegram-бота через @BotFather и получите токен.
2. Добавьте токен в файл конфигурации или переменную окружения.
3. Запустите бота:
   ```bash
   python main.py
   ```

## Структура проекта

- `main.py` — точка входа для запуска бота
- `README.md` — документация проекта
